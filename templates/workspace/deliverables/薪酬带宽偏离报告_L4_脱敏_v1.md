## 1. 口径定义（L4 区间口径 · L4-IR-1.0）

### 1.1 纳入与排除

| 类别 | 规则 |
|---|---|
| 纳入 | 口径时点在职；职级判定为 **L4**（专业序列第 4 级）；FTE ≥ 0.6；入职满 3 个月 |
| 排除 | 试用期未满 3 个月；停薪留职 / 长期病假 ≥ 30 天；调动过渡期（未生效新职级）；口径外补贴与一次性奖金；同一人多次记录（保留主岗） |
| 兼职/多岗 | 按主岗职级归集，人工成本按 FTE 分摊后合并为一条记录 |

### 1.2 薪酬口径

- **年固定现金（Annual Fixed Cash, AFC）** = 基薪 × 12 + 固定津贴（不含年终奖、销售提成、股权/长期激励、一次性签字费、报销性补贴）。
- 全时当量折算：`AFC = AFC_原始 × (1 / FTE)`；FTE < 1.0 者在明细标注 `FTE_ADJ=Y`。
- 币种与汇率：统一折人民币，汇率取口径时点集团财务发布月均价（USD/CNY、HKD/CNY 各一档），汇率表随报告归档。
- 年化：不足 12 个月的在册周期按实际发放年化（如 9 个月发放额 ÷ 9 × 12）。

### 1.3 带宽（区间）定义

L4 统一采用 **中位值 ±20%** 的对称带宽（`band_width = 0.20`）：

```
Min  = Mid × (1 − 0.20)
Max  = Mid × (1 + 0.20)
P25  = Min + (Mid − Min) × 0.5
P75  = Mid + (Max − Mid) × 0.5
```

- 带宽宽度 20% 为**建议值**，需薪酬委员会确认（见 §8 待决事项 D1）。
- 跨序列/跨地区若存在差异化带宽，必须按「职级 × 地区档」分别建带，禁止混用同一 Mid。

### 1.4 偏离度指标（本报告核心口径）

| 指标 | 公式 | 含义 |
|---|---|---|
| **CR**（Compa-Ratio） | `实际AFC ÷ Mid` | 相对带宽中位值的位置；本报告主判定指标 |
| **PIR**（Position in Range） | `(实际AFC − Min) ÷ (Max − Min)` | 区间内相对位置，0=贴下限，1=贴上限，>1 或 <0 即出带 |
| 偏离额 | `实际AFC − Mid` | 绝对偏离（仅授权视图展示） |

### 1.5 判定分带（三色 + 出带）

| 判定 | 条件（CR） | 颜色 | 处置（见 §4） |
|---|---|---|---|
| 合规 | 0.90 ≤ CR ≤ 1.10 | 🟢 绿 | 无需动作，季度抽样复核 |
| 观察 | 1.10 < CR ≤ 1.15 或 0.85 ≤ CR < 0.90 | 🟡 黄 | 记录观察，纳入下次调薪池 |
| 超上限 | CR > 1.15 | 🔴 红（出带） | 30 天内说明或调整 |
| 低于下限 | CR < 0.85 | 🔴 红（出带） | 优先处理，公平性/合规风险 |

> 判定阈值 ±10% 为合规带、±15% 为红线，属**建议口径**，需薪酬委员会确认（D2）。

### 1.6 统计抑制与稳健性

- **k-匿名抑制**：任何聚合单元（部门 × 职级 × 分带）样本 **< 5 人** 不单列，向上合并至一级部门或「其他」。
- 极值处理：单列表述中每单元**不单独展示 Top1 / Bottom1** 个体，仅以区间（P10/P90）呈现。
- 异常值判定：`|CR − 1| > 0.5` 视为数据质量疑点，先入「待核查清单」，不直接参与分带结论。

## 2. 脱敏规则（DS-1，本报告强制生效）

### 2.1 字段级脱敏映射

| 原字段 | 脱敏后 | 方法 |
|---|---|---|
| 姓名 | `EMP-####` | HMAC-SHA256(工号, salt) 取模 6 位；**报告不含映射表** |
| 工号 | 同 `EMP-####` | 不可逆；salt 由 HRIS 管理员单独保管，年轮换 |
| 直属上级 | `MAN-####` | 同上，独立 salt |
| 部门 | 一级部门名 | 不下钻三级；**人数 < 5 的部门合并为「其他」** |
| 岗位名称 | 岗位族（IT/研发/职能/销售…） | 泛化，去除可识别的窄口径岗位 |
| 绩效 | P1–P5 档位 | 区间化，去掉具体分数 |
| 司龄 | 0–1 / 1–3 / 3–5 / 5+ 年 | 分箱 |
| 薪酬绝对值 | **指数（Mid = 100）** | 相对化；`指数 = CR × 100`，保留 1 位小数 |
| 薪酬绝对值（授权视图） | 四舍五入至千位 | 仅 §6.2 授权角色可见，单独文件、单独审批 |
| 地区/工作地 | 城市档（一线/新一线/其他） | 低当量城市合并 |

### 2.2 反推（重识别）防护校验

1. 任一维度组合（一级部门 × 岗位族 × 司龄箱 × 绩效档）唯一命中人数 = 1 时，强制并入相邻维度。
2. 薪酬指数在同一单元内若仅 1 个取值，单元整体隐藏。
3. 跨报告比对防护：本报告与上期报告使用**同一 salt 版本**时，仅在受控视图内可比；外发版重算 salt。

### 2.3 例外与受控明细

涉及法定报备（最低工资、同工同酬举证、集体协商）、劳动仲裁或审计取证的，需保留可核对明细：走 **§6.1 敏感明细调阅审批（HRVP + 法务双签）**，明细单独出件、单独编号、单独留存日志，且不并入本报告正文。

## 7. 一键复算脚本（数据落盘后执行）

保存为 `templates/workspace/deliverables/tools/comp_band_deviation.py`，运行：

```bash
python comp_band_deviation.py \
  --band   templates/workspace/data/comp/comp_band_L4.csv \
  --emp    templates/workspace/data/comp/comp_employees.csv \
  --asof   2025-09-30 --k 5 --observe 0.10 --red 0.15 \
  --out    templates/workspace/deliverables/
```

脚本要点（口径硬编码在代码中，避免口径漂移）：

1. 读带宽表 → 校验 `min<mid<max`，若缺 `min/max` 则按 `band_width=0.20` 生成；
2. 读在册表 → 过滤 `level=L4`、`status∈{在职,试用}`、`hire_date ≤ asof − 3 个月`、`fte ≥ 0.6`，剔除 `top_up_items`；
3. `AFC = annual_fixed_cash_raw × (1/fte)`，按币种折算 CNY，年化；
4. 计算 `CR / PIR / band_flag`；`|CR−1|>0.5` 转「待核查」；
5. 脱敏：`emp_code = HMAC-SHA256(emp_id, salt)` → 6 位；`dept_l1` 泛化；`<5 人` 单元并入「其他」；
6. 输出三张表：`明细_脱敏.csv`、`汇总_分布.csv`、`分组_抑制后.csv`，并写 `口径指纹`（band_width、observe、red、k、salt 版本、asof）用于版本可追溯；
7. 自检：`明细行数 == 汇总行数`；`Mid` 与带宽表逐组织一致；重复 `emp_id` 报错。
