## 2. 调薪提案双审批流程（全流程设计）

### 2.1 角色与职责

| 角色 | 岗位 | 职责 |
|---|---|---|
| 提案人 | 直线经理 / HRBP | 填写提案单、附业绩与带宽依据 |
| 一级审批 | 用人部门负责人 | 业务必要性、绩效与继任风险 |
| 复核（HR） | 人力资源部（薪酬） | 带宽合规、内部公平性、口径统一 |
| 二级审批 | 财务部（预算/成本） | 预算占用、成本测算、额度红线 |
| 加签（L4） | 分管副总 / 薪酬委员会 | 超带宽、超比例、超批量例外 |
| 备案与执行 | HR 薪酬 + 财务 | 生效、薪酬系统变更、归档留痕 |

### 2.2 分级规则（金额 ∨ 比例 ∨ 职级，**取最高级**）

| 等级 | 触发条件（满足任一） | 审批链 | 是否双审批 |
|---|---|---|---|
| L1 | 涨幅 < 5% 且 金额 < 1 万元 | 部门负责人 | 否（单审批） |
| L2 | 涨幅 5%–10% 或 金额 1–2 万元 | 部门负责人 → HR 备案 | 否（单审批链） |
| L3 | 涨幅 10%–15% 或 金额 2–5 万元 或 职级 ≥ P6 / M2 | 部门负责人 → HR 负责人 → 财务负责人 | **是** |
| L4 | 涨幅 ≥ 15% 或 金额 ≥ 5 万元 或 触及带宽 p75 或 单部门本批额度超红线 | 部门负责人 → HR 负责人 → 财务负责人 → 分管副总/薪酬委员会 | **是（含加签）** |

### 2.3 状态机

```
草稿 ──提交──> 待一级审批 ──通过──> [HR 复核] ──通过──> [财务复核] ──通过──> 待生效 ──生效日──> 已生效 ──> 已归档
   │                │                    │                    │
   │                └──驳回──> 已退回（提案人可修改后重新提交，保留原版本）
   └──撤回────────> 已撤回（仅一级审批前可撤回）
任一节点超时 24h ──> 自动提醒；再超 24h ──> 升级至上一级或 HR 负责人
```

### 2.5 硬门禁（不满足即系统拦截，不可人工跳过）

- **G1 带宽**：调整后年固定薪 ≤ 对应带宽 **p75**，且原则上 ≥ p25；低于 p25 或高于 p75 需 L4 + 书面临时偏离说明。
- **G2 预算**：部门本批调薪总额 ≤ 部门剩余预算 × **30%**；同时调整后部门预算已用率 ≤ **95%**。
- **G3 比例**：单人单次涨幅 ≤ **30%**；12 个月内同一人累计涨幅 ≤ **40%**。
- **G4 资格**：绩效 C 及以下不得调薪；入职 < 6 个月需 L3 以上并附转正评估。

### 2.6 冲突、回避与例外

- **回避**：提案人不得审批本人提案（含为自己名下员工提案时须由上级审批）。
- **重复提交检测**：同一员工同一调薪周期只允许 1 张有效提案单，重复提交自动合并并告警。
- **批量绕过防护**：同一部门同一周期提案 ≥ 5 条或合计额 > 红线，自动升为 L4 走委员会。
- **超时升级**：见 2.3 状态机。

### 2.7 留痕与审计

审批留痕表字段：`提案编号 | 节点 | 处理人(岗位+脱敏姓名) | 意见 | 时间戳(ISO8601) | 结果 | 附件SHA256 | 版本号`。日志**只追加不修改**；薪酬数值变更以「版本 + 差异」方式留痕，禁止覆盖历史版本。

## 附录 B 术语与单位

- **带宽（band）**：同职级薪酬区间，p25/p50/p75 为分位值，单位万元/年；bp50 = 薪酬 ÷ 带宽中位值。
- **双审批**：两个独立审批节点（HR 负责人 + 财务负责人）均通过方为通过；L4 追加分管副总/薪酬委员会加签。
- **单位换算**：1 万元 = 10 000 元。例：EXP-8815 42 800 元 = 4.28 万元（L4 / 双审批中）。
