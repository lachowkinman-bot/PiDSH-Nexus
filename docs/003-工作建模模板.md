# 工作建模模板

> 用途：把任意 HR 岗位/职能建模成 Agent 可执行的"数据 → 技能 → 流程 → 决策 → 指标"五要素。
> 用法：复制一份，按职能填写；括号内为填写说明，示例见文末。

---

| 所属部门 / 负责人 | （如：人力资源部 / 张三） |
| 服务对象 | （如：候选人、在岗员工、业务部门负责人） |

| 现有工具 / 系统 | （当前用什么做，如 Excel、飞书、HR SaaS） |

## 二、数据资产

### 输入数据（Agent 要读的表）
| 表名 / 文件 | 关键字段 | 数据来源 | 更新频率 | 脱敏要求 |
|---|---|---|---|---|
| 例：candidates.csv | 姓名/岗位/阶段/跟进日期 | 招聘系统导出 | 每日 | 报告输出用代号 |

### 输出产物（Agent 要写的文件）
| 产物 | 格式 | 存放位置 | 频率 |
|---|---|---|---|
| 例：招聘漏斗周报 | Markdown | reports/ | 每周一 |

## 示例：招聘职能（填好的样子）

| 项目 | 内容 |
|---|---|
| 核心目标 | 缩短招聘周期、提升漏斗转化，候选人信息不流失 |
| 输入 | candidates.csv（姓名/岗位/阶段/跟进日期/来源） |

| 技能 | skills/recruitment/SKILL.md，触发词"招聘漏斗周报" |
| KPI | 面试转化率 ≥20%；平均周期 ≤30 天 |
| 交接要点 | 简历附件在本地文件夹，别让 Agent 直接删候选人记录 |
