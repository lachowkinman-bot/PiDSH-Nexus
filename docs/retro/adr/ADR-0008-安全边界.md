# ADR-0008 · 安全边界：仅 127.0.0.1 + CVE 处置 + redact 物理闸门 + 供应链三件套

- **状态**：已采纳（as-built）｜**决策日**：2026-09-27 09:35/09:49（硬约束）→ 第三轮补证｜**模块**：M12
- **证据**：`015` §1（C3/C4）、L572-594（CVE）、L90（redact_gate）、L725-727（EAP）、L900/L992（U6 新鲜度）；`reports/security-check.md`；`reports/security-scan/scan-summary.json`；`reports/l3-session-interactions.md`

## 背景
工作台面向 HR/财务等**个体级敏感数据**场景，且宿主 dsh 有真实的沙箱逃逸 CVE；插件生态 23/24 为单人维护（bus factor = 1）；曾发现"免 Key 的视觉插件默认把截图外传第三方"。

## 决策
1. **网络**：Web UI 仅绑 `127.0.0.1`，**永禁 0.0.0.0 / 局域网隧道**（CVE-2026-82533 的利用前提就是 3080 暴露）；下载仅 http/https + host 白名单 + 拒绝回环/私有/保留地址。
2. **CVE**：锁 dsh ≥0.1.2（实锁 0.1.7-rc.2）+ 断言写入脚本；CVE-2026-82533 处置红线写进 `setup.iss` 注释。
3. **脱敏**：`redact_gate` 作为**物理闸门**——个体级敏感数据外流前必须被改写（个体薪酬只出区间、健康数据只出聚合、EAP 只出匿名编号）；**安全单调性 C4**（`min_level` 只能增大、`redact.fields` 只能增广、`pii_allowed` 只能 false）。
4. **EAP 五条**：禁联网 / 禁入记忆层（`memory.exclude`）/ 双审批 + 匿名化 / 独立命名空间 / 全量留痕。
5. **供应链 U6 三件套**：全量 OSV/npm audit（0 高危或豁免留痕）+ provenance/维护者核验 + top20 下载量包代码级抽查；扫描结论**有新鲜度**（只可引用不可转贴）。

## 被否决的方案
| 方案 | 否决理由 |
|---|---|
| **"哈希锁定 + host 白名单 = 已检查安全"** | 1.0 复盘判定：只覆盖**供应链完整性**，不覆盖**代码安全性** |
| **免 Key 视觉插件** | 默认把截图外传第三方——对 HR 数据是红线，必须禁用 |
| **把 3080 暴露到局域网/公网隧道** | 直接触发 CVE-2026-82533 远程可利用条件 |
| **以上游 README/配置文件存在性冒充脱敏生效** | 违反 §14.6；脱敏命中曾如实登记 `BLOCKED(credential)`，第三轮才用模型侧可见的 `[REDACTED:…]` 补证 |
| **删除失败记录 / 用 md 报告冒充 UI 呈现** | V 级一票否决 |
