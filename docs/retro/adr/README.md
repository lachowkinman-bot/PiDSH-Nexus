2. **再读** [ADR-0002](ADR-0002-交付形态-插件化原生定制.md) → [ADR-0006](ADR-0006-UI形态-独立单页应用.md) → [ADR-0005](ADR-0005-桌面形态-D1D2.md)——形态三次收敛的主线。
3. **工程接手**读 [ADR-0012](ADR-0012-安装模型与离线打包.md) + [ADR-0013](ADR-0013-profile依赖治理.md)——两类"装出来不能用"的实战事故。
4. **引用旧文档前**先看 `../RETRO-PRD.md` §4 更正台账（19 条）。

## 标注约定
- `【用户否决】`＝用户明确拒绝过的方案（优先级最高，不得重新提出）。
- `⚠️更正`＝该模块/决策的旧结论已失效，引用旧文档前必读。
- 状态三态：已采纳（as-built）／未达成（gap，如实登记）／已撤回（结论被推翻）。
