# ADR-0012 · 安装模型：每用户安装 + 离线自举 + 显式工具链打包

- **状态**：已采纳（as-built，R6）｜**决策日**：2026-09-29（R6）｜**模块**：M3
- **证据**：`scripts/installer/win/setup.iss`（+`setup-x.iss`）、`scripts/workbench.ps1|.sh` install 分支、`scripts/launch.ps1`；`reports/desktop-acceptance.md`；`.work/iss-exclude-test/`（探针）；`offline/npm/pnpm-10.32.1.tgz`

## 背景
R5 结束时"桌面版"在开发机可用，但**装出来的产品根本不能用**，共四条断点 + 两条静默致命：
1. 安装包**不含** app.html / workbench-ui-plugin / src（旧 exe 早于 `[Files]` 修改）；
2. postinstall **从不把工作台插件装进 profile** → 产品没有 ⟡ 工作台 面板、`/app-page` 404；
3. 离线包**不含 pnpm**（`dsh plugin add` 是**转发给 pnpm** 的）→ 干净机全部 exit 127；
4. 装到 **Program Files** 且无权限设置 → 普通用户双击后运行期写入全部 EPERM/EACCES（HTTP 500）。

## 决策
1. **每用户安装**：`PrivilegesRequired=lowest` → `{autopf}` 自动落 `%LOCALAPPDATA%\Programs\UniversalWorkbench`；快捷方式改 `{autodesktop}`/`{autoprograms}`。契约 §10.1 的 `DefaultDirName={autopf}\UniversalWorkbench` **一字未改**。
2. **pnpm 随包 + install 第 0 步自举**：`offline/npm/pnpm-10.32.1.tgz`（SHA256 `9b943b94…f233e3`，与 registry integrity 逐字核验）；PATH 无 pnpm 时 `npm i -g <tgz>`。
3. **Node 工具链显式列举打包**：`node.exe` + `npm*`/`npx*`/`corepack*`/`pnpm*` + `node_modules/{npm,corepack,pnpm}`。
4. **install 第 9 步装工作台插件 + 硬断言**：`dsh plugin --profile web add <插件目录>`，并断言 `node_modules/@workbench/client-ui/package.json` 存在 **且** 已登记 `dsh.profile.bundles`（禁止静默成功）。
5. **launch.ps1 自愈**：缺引擎或插件时先静默跑一次离线 install（覆盖"静默安装跳过 postinstall"与"手工拷贝目录"）。
6. `[Run]` 补 `WorkingDir:{app}`；脚本自带 `Set-Location $Root`。

## 被否决的方案
| 方案 | 否决理由 |
|---|---|
| **Program Files + 手工 ACL** | 授予普通用户写 Program Files 子目录 = 提权面（`unins000.exe` 以管理员运行）+ 升级覆盖风险 |
| **Program Files + 数据全部外置** | 需改插件取数根（`BUNDLE_ROOT`）并重跑全部 UI 证据，风险高；且多用户场景本就是 PRD 非目标 |
| **`Excludes:"node_modules"`** | **实测炸过**：把 **npm 本体**一起排掉（探针 Tree B 只剩 `node.exe`+`npm.cmd`）→ 干净机装不了任何东西 |
| **`Excludes:"node_modules\@*"`** | **实测炸过**：ISCC pattern 匹配**任意层级**，把 npm 自己的 `@npmcli/@isaacs/@sigstore/@gar/@tufjs` 一并排掉（npm 内部依赖 113 vs 118）→ 首步 `cjs/loader` 报错 |
| **假设目标机已有 pnpm** | `dsh plugin add` 转发 pnpm；干净机 exit 127 |
| **手工 `cp` 修复脚本进产品** | 被安全钩子正确拦截（绕过扫描）→ 改为**从修复后的源重建安装包** |
| **保留 npm 的 `$ErrorActionPreference='Stop'`** | PS 5.1 会把 native 的 stderr（npm warn）**升级为终止错误**，安装第一步即死 → 改为只认 `$LASTEXITCODE`（与脚本硬规则一致） |

## 后果
- R6 实测：装后 `install-log.csv` **25/25 exit 0**（引擎 + 23 P0/P1 + 插件），幂等复跑仍 25/25；**字面双击快捷方式** → 12 秒后新 Edge app 窗口 + `/app-page` 200；**非提权写入**三路落盘；`verify-app` **41/41**；卸载干净且**运行期数据保留**。
- 终版产物 **336,101,645 B / SHA256 `cc624824…bcdb`**。
- **未达标**：严格离线（引擎 tgz 有 81 个 registry 依赖、无 bundled → 传递依赖走 registry/热缓存）；第二台干净机；macOS。
