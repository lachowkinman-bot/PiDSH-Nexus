# ADR-0005 · 桌面形态：D1 安装器保底 + app 模式窗口；D2 内嵌壳留作条件升级

- **状态**：已采纳（as-built，D1 交付；D2 未达成）｜**决策日**：2026-09-27（015 §10.2 机械裁定）→ 2026-09-29 用户追加形态指令｜**模块**：M3/M4
- **证据**：`015` §10.1/§10.2/§10.3（L787-819）、U14 行（L907）；`docs/PRD-桌面应用-基线.md` §5；`reports/desktop-acceptance.md`；会话 `sess_630e78a2` 09-29 18:11

## 背景
用户要求"交付桌面应用"（F1：双击启动）。当时存在两条路：
- **D1 保底**：安装器 + launcher（离线内嵌、双击启动、快捷方式）；
- **D2 升级**：本地构建 dsh-web 内嵌壳（webview/托盘/通知为 P1 增强）。

`015 §10.2` 给了**机械裁定**：D2 需"构建成功且 25 项 UI 测试 ≥12 绿且 3 项前后端连通"；**任一不满足 → 自动交付 D1**，gap 登记"壳未达标"，**禁止虚报形态**。

## 决策
- **D1 交付**：Inno Setup 安装器（见 ADR-0012）+ `launch.ps1`；
- **桌面窗口形态 = Edge/Chrome `--app=` 模式窗口**（无地址栏、无标签页、独立任务栏项、独立 `app-profile` 数据目录）；
- **D2 未达成并如实登记**：`offline/github/` 为空（dsh-web 源码未入包，dev 分支 zip 实测 452MB → 只能 `git clone --depth 1`，本环境不具备条件）。

## 被否决的方案
| 方案 | 否决理由 |
|---|---|
| **自研原生壳（Electron / Tauri）** | "均不在现包内"——需新增运行时与构建链（离线包 +150~250MB）、重做打包与签名、工期显著增加，且违背"资源全部现成预置"的资源边界 |
| **构建 dsh-web 官方壳** | 需联网 clone 452MB dev 分支并本地构建；且 U14 机械裁定要求"25 项 UI 测试 ≥12 绿 + 3 项前后端连通"，当前环境不可达 → 自动回落 D1 |
| **重仓库内嵌**（`anywhere-labs/dsh-desktop` 191MB / `dataelement/dsh-desktop` 18MB） | 体积与离线包预算冲突 → 改 `git clone --depth 1` 浅克隆兜底 |
| **网页版（默认浏览器标签页）** | `【用户否决】`用户原话：「**要使用桌面版，而非网页版**」——原 `Start-Process "http://…"` 就是开标签页，与要求不符 |
| **承诺"原生二进制"** | 实际是 app 模式窗口（**依赖系统自带 Edge**），虚报形态触犯 §14.6 与 V 级禁令 |

## 后果
- 用户得到可用的桌面入口（字面双击实测：快捷方式 → 3080 起壳 → 12 秒后新窗口），且离线包不增大。
- 代价/限制：①依赖 Edge/Chrome 存在；②app 窗口的 localStorage 与"浏览器打开同一 URL""`file://` 双击"**互不相通**（已在交接文档中要求用户固定走图标入口）。
- **未达标项**：严格离线安装、第二台干净机、macOS 侧（见 RETRO-PRD §5）。
