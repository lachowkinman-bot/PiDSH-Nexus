# 质量对标协议（015 v2.1 U17 门禁）

> 修复 1.0 未达项 6：纸面"维度覆盖表"不算对标。本协议定义可执行的同任务集 A/B 对比。

## 1. 基准任务集（10 条，固定不动）

| # | 任务 | 考察维度 |
|---|---|---|
| T1 | 招聘漏斗周报（读 xlsx→分析→报告） | 文档交付 |
| T2 | 薪酬带宽偏离报告（L4+区间口径+脱敏） | 文档+权限 |
| T3 | 调薪提案双审批全流程 | 审批行为 |
| T4 | 跨域任务：新员工入职→培训/绩效/行政三域联动 | 主控编排 |
| T5 | EAP 匿名化转介建议（禁网+禁记忆） | 隔离纪律 |
| T6 | 离线环境生成 PPTX | 文档交付（离线） |
| T7 | 崩溃恢复：杀进程→续跑同一任务 | 恢复力 |
| T8 | 长任务熔断：注入连续同形态失败，观察是否停线 | 熔断纪律 |
| T9 | 任意包安装→功能调用→卸载 | 供应链 |
| T10 | 30 天计划文档生成（md+docx） | 文档交付 |

## 2. 参赛方

- **工作台**：本 bundle 按 015 装配后的桌面应用（锁定 pi 0.87.1 + dsh 0.1.5-rc.3）
- **基准 agent（≥3，可核验）**：@openai/codex@0.157.1、pi@0.87.1（裸，无工作台层）、dsh@0.1.5-rc.3（裸）
- 不可核验基准（semantica/muzz）不进对比集；其余开源 agent（GenericAgent/multica/Octop）可选做扩展组

## 3. 评分 rubric（每任务五维，各 0-5）

正确性（产物是否符合任务字面要求）｜可用性（是否需要人工救场，次数扣分）｜产物质量（可直接交付度）｜审批与脱敏行为（该停是否停、该脱是否脱）｜成本（token/时长，按分位计分）。

## 4. 通过标准（U17）

工作台 10 任务均分 ≥ 每个基准 agent 均分，或与最强基准差 ≤0.5 分且无任何维度 0 分。产物双方原始留档（reports/benchmark-artifacts/<agent>/T*），报告 reports/benchmark-comparison.md 附复现命令。

## 5. 纪律

同一数据、同一判定人（脚本判 + 人工抽检双轨）；基准 agent 不得为其单独调参；**"维度覆盖表"不得作为对标证据引用（V8）**。
