## 7. 故障排查

| 现象 | 处理 |
|---|---|
| 插件装不上（Ignored build scripts） | `cd ~/.dsh/profiles/web && pnpm approve-builds --all` 后重装 |
| 报 minimum release age | 锁版本重装：`dsh plugin --profile web add <包名>@<版本>` |
| 终端 node-pty 失败 | `pnpm approve-builds --all && pnpm rebuild node-pty`，重启 dsh |
| Agent 拒绝操作 | 查看权限策略与审批设置，按需改为 ask（不要全开） |

## 8. 权限与审批

| 范围 | 策略 | 说明 |
|---|---|---|
| reports/ 写入 | 放行 | Agent 直接写 |
| data/ 主数据修改 | 审批 | 先列改动清单 |
| 终端危险命令 | 审批 / 禁止 | 按 DSH 权限策略配置 |
