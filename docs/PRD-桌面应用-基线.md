# PRD · Universal Workbench 全能 Agent 工作台桌面应用（基线版 v0.9）

> 015 §9.1 自制层预置文档。Agent 按 runner-profile.json 与 D1/D2 形态裁定结果**定制化**后交付；非目标不得擅自扩scope。

## 1. 产品定位

给业务人员（HR / 财务 / 销售 / 行政等非工程角色）的**单机全能 Agent 工作台桌面应用**：离线可装、双击可用、审批与脱敏内建、12 业务域场景即装即用。

一句话：**人负责目标、判断和授权；AI 负责规划、执行、检查、记录和持续推进。**（继承 010-03 §51）

## 2. 用户

| 用户 | 场景 | 关键诉求 |
|---|---|---|
| 学员/业务人员（主） | 日常把真实工作交给 AI | 离线安装、零命令行、审批可信、数据不外泄 |
| 讲师（辅助） | 集训营交付与演示 | 一键部署、现场兜底、检查点签核 |
| 维护者 | 升级/回退/审计 | 版本锁定、CR 记录、证据链完整 |
