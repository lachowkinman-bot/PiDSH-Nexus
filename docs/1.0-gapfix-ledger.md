## 过程性根因的方案级对策（复盘 §五/§七）

- "自题自批"闭环 → U15/U16/U17 的通过标志均为**用户可感知证据**（截图/功能调用/A-B 分差），并引入基准 agent 外部对照；
- "计划获批锁定效应" → 015 §0 最小指令增补一句：执行 Agent 必须先把用户原始要求枚举为验收清单再对照门禁（缺口即门禁缺陷，须上报而非免责）；
- "判定系统双向不可靠"（GT-TRN-01 35KB 实物被判 FAIL） → U10 判定规则补"产物非空且结构有效时，FAIL 须人工复核后落账"。
