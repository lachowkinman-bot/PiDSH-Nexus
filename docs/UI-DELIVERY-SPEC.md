# UI 交付规格（015 v2.1 U15 门禁的交付物定义）

> 修复 1.0 未达项 1/2/7：界面 0/12、preset 无生命周期、UI 旅程断裂。本规格是 U15 的唯一 DoD 来源；**lint 通过、文件存在、HTTP 可达均不构成 U15 证据**。

## 1. 必交界面清单（F2-F14 → 页面）

| 功能 | 页面/模块 | 必含交互 | 必含状态 |
|---|---|---|---|
| F2 任务中心 | 首页任务卡列表 | 点卡进入任务详情；筛选 | 进行中/待审批/待输入/失败/空态 |
| F3 12 域入口 + F14 preset 装载器 | 域导航 + preset 卡片选择器 | **选→应用→运行→保存→切换** 五操作；切换后界面即时变化 | 未装载/装载中/已装载/不兼容 |
| F4 审批中心 | 待审列表 + 审批详情 | 批准/拒绝/查看详情；拒绝后任务回到规划态 | 待审/已批/已拒/空态 |
| F5 脱敏与审计查看器 | redact 日志表 + trajectory 回放 | 按任务过滤；点击事件展开 | 有日志/空/REDACTED 高亮 |
| F6 记忆与知识面板 | 记忆条目 + KG 召回查询 | 写入/召回/EAP 排除开关（灰显） | 命中/未命中/EAP 禁用 |
| F10 GT 冒烟入口 | 域选择 + 一键跑 | UI 内触发并展示实时进度 | 跑前/跑中/通过/失败 |
| F12 EAP 入口 | 独立命名空间页 | L4+ 横幅；禁网/禁记忆指示 | 正常/隔离生效 |
| F13 主控编排 | Chief of Staff 编排视图 | 跨域任务拆解树 + 子代理状态 | 分派中/并行/汇总/失败 |
| 12 域工作台 | 每域 1 个工作台页 | 数据表展示 + 域技能触发 + 域工作流入口 | 有数据/空数据/权限不足 |

技术约束：基于 dsh web 的插件机制（genui/panel 类）或 dsh-web 壳扩展实现；组件文件必须落盘于 `templates/ui/` 并纳入 U14 安装器打包。**纯 Markdown 报告不构成任何一页。**

## 2. preset 生命周期 DoD（F14）

| 操作 | 定义 | 证据 |
|---|---|---|
| 选 | UI 列出 14 个 Scene（名称/域/能力/GT 数） | 截图：列表含全部 Scene |
| 用 | 点击应用 → 界面切换为该域工作台 → 域技能可触发 | 截图：应用后界面 + 触发成功 |
| 存 | 应用状态持久化（重启后仍在） | 截图：重启前后对比 |
| 切 | 切换到另一域 → 界面与权限随 Scene 更新 | 截图：切换前后对比 |

运行时消费方 ≥1（前端代码真实读取 manifests/scenes/*.yaml），grep 证据随 U15 提交；**离线脚本读取不算**。

## 3. 截图证据规范

- png 格式，命名 `reports/ui-walkthrough/<F号或域码>-<操作>-<序号>.png`；≥13 张（13 功能）+ ≥12 张（12 域工作台）
- 每张配一行说明（操作步骤 + 预期 vs 实际）；`ui-walkthrough.md` 汇总索引
- 禁止：用浏览器控制台改 DOM 后截图；用 CLI 产物替代界面状态

## 4. workspace 门控攻关义务（1.0 阻塞点）

安装器/首启必须以 `DSH_HOME` + 预置 profile 把工作区选择做成**配置化预置**，用户双击后直达已选工作区界面；若引擎版本引入新门控，攻关时限 2h，超时按 §10.3 停线上报——**禁止以 headless CLI 验证替代 UI 旅程**。

## 5. 逐域差异化界面与机械 DoD（v2.2 新增，修复"13 域同构页"）

- **机械清单**：`manifests/domain-ui-checklist.csv`——13 域 × 必含独有业务元素（如 sales=CRM 管道看板、fin=报销单表单、rec=面试安排表、comp=带宽偏离图、er-eap=EAP 转介表单）× 证据截图；逐项打勾，缺一即 U15 FAIL。
- **F7/F8/F11 三页补齐**：F7 离线模式指示页、F8 升级与回退入口页、F11 安装自检报告页（2.0 实测三页缺失）。
- **交互级 DoD（F14）**：选/用/存/切每操作产生对应审计事件（preset.save、preset.switch ≥1）+ 状态变更前后截图 + `workspace/presets/saved-*.json` 产物；**"切"必须是不同 sceneId**（2.0 实测 btnSwitch 与 btnApply 同参，"切"成"用"别名）。
- **preset 可新建/编辑**：基于 Scene 模板派生用户 preset（workspace/presets/user-*.yaml）并持久化。
- **同构判定规则**：任意两域工作台共享同一 DOM 骨架且无 checklist 独有元素 = FAIL（2.0 的 13 张同构截图不得再现）。
- **技能按钮行为断言**：点击域技能必须调用该技能对应端点（data-skill 生效），禁止全部落域 GT（2.0 实测忽略 data-skill）。
